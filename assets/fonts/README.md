# Game font

Chakra Petch by The Chakra Petch Project Authors, bundled unmodified from
https://github.com/google/fonts/tree/main/ofl/chakrapetch on October 25, 2026.

`ChakraPetch-Medium.ttf` and `ChakraPetch-SemiBold.ttf` are upstream static fonts.
The SIL Open Font License is included in `ChakraPetch-OFL.txt` and must ship with the font.
The game antialiases this squared, retro-shaped family for readable small lettering.
No system font installation or network access is needed at runtime.
